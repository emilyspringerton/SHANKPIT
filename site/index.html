SHANKPIT

An engine that runs the same rules as the other two worlds. UDP-authoritative, retro-rendered, and built out of PARENA decisions emitted to C — so a threshold is edited once and every host follows.

shankpit-460 · play it here, from this deploy TRAPX VS0 · the city sandbox Roblox 460 · the install kit

What it is right now

  • Server A UDP, server-authoritative game server; client prediction against the same integer rules.
  • Client Lobby and client app with local and networked flows, linked scenes and portals.
  • Renderer Retro stack: procedural textures, sky, fog, stylized lighting, GOLDENBAND skinned meshes.
  • Modes Team deathmatch, capture the flag, story mode, bots for cold starts.
  • Simulation NPC drifting, slippery surfaces, DEADWEIGHT's card ladder, the cosy verbs.
  • City TRAPX VS0: Watchers, Field Offices, K9 doctrine, receipts — in C and in the browser. Play the city sandbox on WOTAN.

One decision, three worlds

Every number two repos must agree on lives in PARENA as a .prn file and is emitted twice: to C here, and to Luau or TypeScript for the Roblox and browser halves. The generated files are committed, never hand-edited, and both sides assert the same fixture rows, so a drifting port is a red test instead of two worlds quietly disagreeing.

The clean room, playable

PARENA clean room is the from-scratch SHANKPIT: the loop, the renderer, both modes and the network wire are .prn rules compiled at build time, and the only hand-written C left is the SDL2/raster/socket host. It boots into ZOMBIES as the lobby; 2 switches to shankpit-460's arena-shooter FFA.

Download the latest Windows / Linux build

The Windows zip is the same shape as the main game's: ShankPit_Client/ holding ShankPit.exe, SDL2.dll and PLAY.bat. The Linux zip holds ShankPit_Client_Linux/ with a PLAY.sh.

Honest status

shankpit-460 is served from this deploy: the game, its wasm module and the stylesheet it needs are copied out of the WOTAN repository at build time, so the playable build cannot drift from the one WOTAN ships. The rest of WOTAN — TRAPX, BRAWLPIT, DEADWEIGHT — lives on WOTAN's own GitHub Pages site, because the wotan.okemily.com origin is not answering.

A generated rules module being tested is not the same as a feature being played. The C hosts that the lobby does not call yet, the service writes never observed landing, and the rules that are decided but not wired are all named in the documents — the index says which is which, and none of them are hidden behind a green badge.
