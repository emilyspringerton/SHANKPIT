Tools

Vehicle places a vehicle_spawn_<kind> tile where you click — the same name convention the buggy spawner uses, so IDUNA NOCK and this editor export the same thing.

Lofts

The lofts are composed levels (levels/lofts/): a bay has the geometry, a floor references three bays, a pair stacks two floors, and the eight buildings reference pairs. Edit a bay or a props module here, then rebuild — that flattens the whole tree into the zombies city and refreshes the baked live default in one step.

Character clips

Binds .gband clips to the 13 gameplay states the engine asks for (anim_idle…anim_climb_loop), validates hashes and rigs, and commits the bundle to git. Raw .fbx exports never go in here: only the baked clips this repo already owns.
